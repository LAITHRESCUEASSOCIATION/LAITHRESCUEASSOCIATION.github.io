سياسة التطوع والخصوصية

جمعية ليث للإنقاذ — نسخة تشغيلية أولية

1. نطاق السياسة: تنظم هذه السياسة التسجيل في منصة الجمعية، إدارة العضوية التطوعية، المشاركة في المهام، استخدام الأنظمة الرقمية، ومعالجة بيانات المتطوعين. ويعد التسجيل طلباً للانضمام وليس قبولاً نهائياً.

2. أهلية القبول: للجمعية حق التحقق من البيانات والمؤهلات والتخصصات والمتطلبات اللازمة لطبيعة العمل التطوعي، وقبول أو رفض أو تعليق الطلب وفق الأنظمة واللوائح والسياسات المعتمدة ودون أن يترتب على تقديم الطلب حق مكتسب في العضوية.

3. صحة البيانات: يلتزم المتطوع بتقديم بيانات صحيحة وحديثة وعدم انتحال صفة أو تقديم مستندات أو مؤهلات غير صحيحة، وإبلاغ الجمعية عند تغير البيانات التي يلزم تحديثها.

4. البيانات التي تجمعها المنصة: قد تشمل الاسم، رقم الهوية/السجل المدني، تاريخ الميلاد، رقم الجوال، البريد الإلكتروني، المدينة، التخصص، حالة العضوية، وسجلات المشاركة والمهام، بالقدر اللازم لإدارة العضوية وأعمال الجمعية.

5. أغراض المعالجة: تستخدم البيانات للتحقق من طلب العضوية، التواصل، إدارة الصلاحيات، توزيع المهام، توثيق المشاركة، الأمن والسلامة، إدارة السجلات، والوفاء بالمتطلبات النظامية ذات الصلة.

6. السرية والأمن: تلتزم الجمعية باتخاذ التدابير التنظيمية والتقنية المناسبة لحماية البيانات، ويمنع على المتطوع مشاركة بيانات الدخول أو تمكين الغير من استخدام حسابه.

7. الإفصاح: لا تفصح الجمعية عن البيانات إلا في الحدود اللازمة للأغراض المعلنة أو عند وجود مسوغ نظامي أو طلب من جهة مختصة، ومع مراعاة الأنظمة السارية.

8. حقوق صاحب البيانات: تمارس حقوق الاطلاع والوصول والتصحيح وطلب الإتلاف أو سحب الموافقة متى كان ذلك منطبقاً، وفق نظام حماية البيانات الشخصية ولوائحه والمسـوغ النظامي للمعالجة.

9. الاحتفاظ والإتلاف: تحتفظ الجمعية بالبيانات للمدة اللازمة لتحقيق الغرض أو للمدة التي يوجبها مسوغ نظامي، ثم تتخذ إجراءات الإتلاف أو إخفاء الهوية بحسب المتطلبات النظامية. لا تعني هذه السياسة الاحتفاظ الدائم برقم الهوية دون مسوغ نظامي.

10. عدم النشاط لمدة 90 يوماً: إذا لم يسجل المتطوع أي مشاركة معتمدة أو نشاط تطوعي لدى الجمعية لمدة تسعين (90) يوماً متصلة، فيجوز للجمعية تعليق أو إغلاق حسابه وسحب الصلاحيات الرقمية والتشغيلية بعد تطبيق الإجراءات الداخلية المعتمدة. ويجوز تقييد إعادة التسجيل بالهوية متى كان ذلك ضرورياً ومتناسباً ومسموحاً نظاماً، مع عدم الاحتفاظ بالبيانات الشخصية بعد انتفاء الغرض إلا بمسوغ نظامي.

11. المهام الميدانية: لا يجوز للمتطوع مباشرة مهمة أو تمثيل الجمعية إلا بعد التكليف أو الإذن وفق الصلاحيات المعتمدة، ويلتزم بتعليمات قائد المهمة ومتطلبات السلامة وعدم تجاوز نطاق التدريب أو الاختصاص.

12. السلامة: للمتطوع رفض أو إيقاف المشاركة عند وجود خطر غير مقبول أو عند عدم امتلاكه التدريب أو التجهيز المطلوب، وعليه إبلاغ المسؤول فوراً. ولا يجوز اتخاذ تصرفات تعرض الأشخاص أو الممتلكات للخطر دون ضرورة أو صلاحية.

13. الهوية والصفة: يمنع استخدام اسم الجمعية أو شعارها أو بطاقاتها أو الزي أو الصفة التطوعية لأغراض شخصية أو تجارية أو إعلامية غير مصرح بها.

14. التصوير والنشر: يمنع نشر صور المصابين أو المفقودين أو مواقع الحالات أو بيانات البلاغات أو المحادثات الداخلية أو أي معلومات سرية دون تصريح ومسوغ مناسب، مع احترام الخصوصية والأنظمة.

15. سرية البلاغات: تعتبر معلومات البلاغات والمهام والبيانات التي يطلع عليها المتطوع بحكم مشاركته معلومات مخصصة للعمل، ويحظر نسخها أو تداولها خارج القنوات المعتمدة.

16. السلوك المهني: يلتزم المتطوع بالاحترام وعدم الإساءة أو التحرش أو التمييز أو الاستغلال أو طلب المقابل المالي من المستفيدين، وبالمحافظة على سمعة الجمعية أثناء أداء العمل التطوعي.

17. تضارب المصالح: يجب الإفصاح عن أي مصلحة شخصية أو مالية قد تؤثر في الحياد عند تنفيذ مهمة أو التعامل مع مستفيد أو مورد أو جهة أخرى.

18. الأجهزة والحسابات: يتحمل المستخدم مسؤولية المحافظة على سرية بيانات دخوله، وإبلاغ الإدارة عن الاشتباه في اختراق الحساب أو فقد الجهاز أو أي استخدام غير مصرح به.

19. الصلاحيات: جميع الصلاحيات الرقمية والميدانية تمنح بحسب الدور والحاجة، وللجمعية تعديلها أو تعليقها أو سحبها عند انتهاء الحاجة أو تغير حالة العضوية أو وجود سبب أمني أو تنظيمي مشروع.

20. المخالفات: يجوز اتخاذ إجراءات إدارية متدرجة بحسب طبيعة المخالفة، ومنها التنبيه أو تقييد الصلاحيات أو التعليق أو إنهاء العضوية، مع مراعاة الأنظمة واللوائح والإجراءات الداخلية المعتمدة.

21. المحتوى المنشور: الأخبار والمقالات والصور التي تنشر عبر حساب الإدارة يجب أن تكون مصرحاً بها، وألا تنتهك حقوق الملكية الفكرية أو الخصوصية أو الأنظمة أو حقوق الغير.

22. الطوارئ: المنصة أداة تنظيمية ولا تحل محل الجهات الرسمية المختصة بالطوارئ، وعلى المستخدمين اتباع تعليمات الجهات المختصة عند الحالات التي تستوجب ذلك.

23. التعديلات: يجوز للجمعية تحديث هذه السياسة عند الحاجة، ويعرض الإصدار المحدث عبر المنصة، ويطلب تجديد الموافقة متى كان ذلك مطلوباً نظاماً أو عند تغير جوهري في أغراض المعالجة.

24. المرجعية النظامية: تطبق هذه السياسة بما لا يتعارض مع الأنظمة واللوائح السارية في المملكة العربية السعودية، وعند التعارض تكون النصوص النظامية الملزمة هي المرجع.

تنبيه: هذه صياغة تشغيلية أولية وليست بديلاً عن المراجعة القانونية واعتماد مجلس إدارة الجمعية وسياسات حماية البيانات الداخلية.
