# فيديو جمعية ليث للإنقاذ (موشن جرافيك)

فيديو طولي 1080×1920 مدته 60 ثانية، بدون تعليق صوتي. مبني بأداة [Remotion](https://www.remotion.dev).

## التشغيل

```console
npm install
npm run dev                                                   # معاينة في Remotion Studio
npx remotion render LaithRescue out/laith-rescue.mp4 --crf=23   # تصدير الفيديو
```

## كيف ينبني الفيديو

- **الإيقاع:** الموسيقى سرعتها 120 BPM، والضربة الوحدة = 15 إطار، والمازورة = 60 إطار. كل قطع بين اللقطات يجي على بداية مازورة، عشان الصورة والموسيقى يضربون مع بعض.
- **اللقطات:** 18 لقطة، وكل لقطة لها نوع انتقال. تلقاها في `SHOTS` داخل `src/laith/theme.ts`.
- **أنواع الانتقالات** (في `src/laith/transitions.tsx`):
  - `zoom`: زوم عبر اللقطة.
  - `push` و`pushX`: دفع سريع رأسي أو أفقي مع ضبابية حركة.
  - `iris`: دائرة تفتح من الوسط.
  - `wipe`: مسح مائل.
  - `split`: الشاشة تنقسم نصين.
  - `flash`: ومضة مع ضربة.
  - `glitch`: تشويش رقمي.
- **المؤثرات الصوتية:** كل نوع انتقال له مؤثر صوتي يتركّب تلقائيًا على وقت القطع.
- **حركة النصوص** (في `src/laith/kit.tsx`):
  - `MaskWords`: الكلمات تطلع من قناع.
  - `Marker`: قلم تحديد أبيض يمر على النص.
  - `Punch`: النص يدخل بضربة.
  - `Track`: الحروف تتباعد ثم تتجمع.
  - `Counter`: عدّاد للأرقام.

## الصور

الصور في `public/photos/` صور حقيقية لفريق الجمعية:
- `laith-team.jpg`: الصورة الأصلية.
- `laith-leader.jpg`: قصّة طولية منها.

عشان تبدّلها:
1. احفظ الصورة الجديدة بنفس الاسم.
2. أو أضف صورة جديدة واستخدمها بمكوّن `Photo` داخل `src/laith/scenes/Photos.tsx`.

الأفضل تكون الصور عالية الدقة، و`laith-leader.jpg` تكون طولية.

## الخط: Thmanyah Serif Text

خط ثمانية مجاني، لكن رخصته تمنع إعادة نشره، ولهذا ما هو مرفوع في المستودع.
حمّله من موقع ثمانية، وانسخ ملفاته داخل `public/fonts/` بهذي الأسماء
(الامتداد يكون `.woff2` أو `.otf` أو `.ttf`):

| الوزن | اسم الملف |
|---|---|
| 400 | `ThmanyahSerifText-Regular` |
| 500 | `ThmanyahSerifText-Medium` |
| 700 | `ThmanyahSerifText-Bold` |
| 900 | `ThmanyahSerifText-Black` |

إذا ما لقى الملفات يستخدم خط Amiri بداله (مرفوع في المستودع ورخصته OFL).

## الموسيقى والمؤثرات

كلها مولّدة برمجيًا بالسكربت `tools/audio.py`، ولذلك ما عليها أي حقوق:
- **الموسيقى:** مقام الحجاز على D مع طبول، وباص فيه ضغط على الإيقاع (sidechain)، وأوتار، وأربيجيو.
- **المؤثرات:** whoosh وswish وimpact وglitch وshimmer وpop وtick.

لإعادة توليدها:

```console
pip install numpy scipy soundfile
python3 tools/audio.py /tmp/aud    # ثم حوّل ملفات wav إلى mp3 داخل public/audio/
```
