# فيديو جمعية ليث للإنقاذ (موشن جرافيك)

فيديو طولي 1080×1920 مدته 60 ثانية، بدون تعليق صوتي. مبني بأداة [Remotion](https://www.remotion.dev).

## التشغيل

```console
npm install
npm run dev                                                   # معاينة في Remotion Studio
npx remotion render LaithRescue out/laith-rescue.mp4 --crf=23   # تصدير الفيديو
```

## كيف ينبني الفيديو

- **الإيقاع:** الموسيقى سرعتها 120 BPM، والمازورة = 60 إطار. كل انتقال يجي على بداية مازورة.
- **اللقطات:** 12 لقطة متصلة، كل لقطة تطلع من اللي قبلها. تلقاها في `SHOTS` داخل `src/laith/theme.ts`.
- **الانتقالات** (في `src/laith/transitions.tsx`). مدتها 24 إطار، واللقطتين يتحركون مع بعض طولها:
  - `zoom`: اللقطة الحالية تندفع نحو الكاميرا، والجديدة تستقر من قريب.
  - `rise`: الجديدة تطلع من تحت فوق الحالية، مع عمق (parallax).
  - `slide`: انزلاق أفقي مع عمق.
  - `iris`: دائرة ناعمة الحواف تفتح من نقطة محددة. مثلًا مشهد الإسعاف يطلع من بطاقة «إسعاف المصابين».
  - `fade`: تلاشي مع تغيير بالتركيز.
  - `leak`: تسرّب ضوء على لحظة الذروة في الموسيقى.
- **المستهدفات:** حركة كاميرا وحدة متصلة تنزل على عمود الأرقام، وكل رقم يعدّ لما يوصل مكانه.
- **حركة النصوص** (في `src/laith/kit.tsx`):
  - `MaskWords`: الكلمات تطلع من قناع.
  - `Marker`: قلم تحديد أبيض يمر على النص.
  - `Punch`: النص يستقر من ضبابية.
  - `Track`: الحروف تتباعد ثم تتجمع.

## الخط: Thmanyah Serif Text

خط ثمانية مجاني، لكن رخصته تمنع إعادة نشره، ولهذا ما هو مرفوع في المستودع.
حمّله من موقع ثمانية، وانسخ ملفاته داخل `public/fonts/` بهذي الأسماء
(الامتداد يكون `.woff2` أو `.otf` أو `.ttf`):

| الوزن | اسم الملف |
|---|---|
| 400 | `ThmanyahSerifText-Regular` |
| 500 | `ThmanyahSerifText-Medium` |
| 700 | `ThmanyahSerifText-Bold` |
| 900 | `ThmanyahSerifText-Black` |

إذا ما لقى الملفات يستخدم خط Amiri بداله (مرفوع في المستودع ورخصته OFL).

## الموسيقى والمؤثرات

كلها مولّدة برمجيًا بالسكربت `tools/audio.py`، ولذلك ما عليها أي حقوق:
- **الموسيقى:** مقام الحجاز على D مع طبول، وباص فيه ضغط على الإيقاع (sidechain)، وأوتار، وأربيجيو.
- **المؤثرات:** whoosh وswish وimpact وshimmer وpop وtick.

لإعادة توليدها:

```console
pip install numpy scipy soundfile
python3 tools/audio.py /tmp/aud    # ثم حوّل ملفات wav إلى mp3 داخل public/audio/
```
