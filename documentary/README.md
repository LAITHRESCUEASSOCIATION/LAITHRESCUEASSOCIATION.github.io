# «جاهزون» — فيلم وثائقي قصير عن جمعية ليث للإنقاذ

حزمة إنتاج كاملة لفيلم وثائقي مدته **3:00** بأسلوب الوثائقيات الحديثة: بلا تعليق صوتي ولا حوار، فقط موسيقى وأنفاس ولمسات بشرية خفيفة.

| الملف | المحتوى |
|---|---|
| `PROMPTS.md` | قائمة اللقطات الثلاثين بالتوقيت، وأمر توليد إنجليزي جاهز لكل لقطة، ومرجع الزي الثابت، وورقة إشارات الصوت |
| `shots.csv` | جدول التوقيت الذي يقرأه سكربت التجميع (المجموع 175ث + 5ث للنهاية = 3:00 بالضبط) |
| `assets/uniform-reference.jpg` | صورة الزي الأصلية، وتُرفع مرجعًا في كل لقطة |
| `assets/laith-logo-gold.png` | الشعار بلون الطباعة الذهبية على السترة، بخلفية شفافة |
| `assets/end-card.png` | لقطة النهاية: الشعار وعبارة «جاهزون عندما تحتاجنا» |
| `assemble.sh` | سكربت يجمع الفيلم النهائي تلقائيًا |

## النسخة المرسومة (جاهزة بدون تصوير)

نسخة رسوم متحركة كاملة من الفيلم، بموسيقى أصلية ومؤثرات صوتية مولّدة برمجيًا، فلا تحتاج حقوق استخدام:

```bash
pip install pycairo scipy numpy pillow
python3 documentary/render/illustrate.py   # يرسم اللقطات الثلاثين في shots/
python3 documentary/render/score.py        # الموسيقى والأنفاس والمؤثرات في music/
./documentary/assemble.sh                  # documentary/laith-documentary.mp4
```

## خطوات الإنتاج (النسخة الواقعية)

1. ولّد كل لقطة من `PROMPTS.md` في Veo 3 أو Sora 2 أو Kling أو Runway، مع رفع `assets/uniform-reference.jpg` مرجعًا. يمكن أيضًا تصوير اللقطات فعليًا مع الفريق.
2. احفظ اللقطات في `shots/01.mp4` … `shots/30.mp4`. يقبل السكربت mp4 وmov، وأي مقاس أو اتجاه أو معدل إطارات.
3. ضع الموسيقى المرخّصة في `music/score.wav` (أو mp3). ملف الأنفاس والمؤثرات `music/foley.wav` اختياري.
4. شغّل:
   ```bash
   ./documentary/assemble.sh                # الناتج: documentary/laith-documentary.mp4
   LETTERBOX=1 ./documentary/assemble.sh    # مع أشرطة سينمائية 2.39:1
   ```

يوحّد السكربت كل اللقطات على 1920×1080 و24 إطارًا في الثانية، ويقصّ كل لقطة على مدتها، أو يثبّت آخر إطار إذا كانت أقصر. ثم يطبّق تدرّجًا لونيًا صحراويًا دافئًا موحّدًا مع حبيبات فيلم، ويضيف لقطة النهاية المتحركة، ويمزج الصوت على ‎-16 LUFS. اللقطة الناقصة تُستبدل بشاشة سوداء، فيمكن مراجعة المونتاج قبل اكتمال كل اللقطات.
