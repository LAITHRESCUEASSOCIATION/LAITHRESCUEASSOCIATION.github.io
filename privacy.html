جمعية ليث للإنقاذ

تحترم جمعية ليث للإنقاذ خصوصية مستخدمي منصتها، وتلتزم بالتعامل مع البيانات الشخصية بطريقة مسؤولة ومحدودة بالقدر اللازم لتقديم خدمات البلاغات وإدارة المتطوعين والتواصل التشغيلي المرتبط بالمهام.

1. البيانات التي قد نجمعها

  • بيانات الحساب مثل الاسم والبريد الإلكتروني ورقم الجوال.
  • بيانات المتطوع مثل الحالة، الدور، وسجل المهام المرتبط بالحساب.
  • بيانات البلاغات التي يرسلها المستخدمون، مثل الوصف والموقع والوسائط المرفقة عند توفرها.
  • بيانات تشغيلية لازمة لتوزيع البلاغات ومتابعة حالتها وإدارة الاستجابة.

2. كيفية استخدام البيانات

  • استقبال البلاغات وإدارتها وتوجيهها للمتطوعين أو الفرق المناسبة.
  • إدارة حسابات المتطوعين والمشرفين وصلاحيات الوصول.
  • إرسال تنبيهات تشغيلية مرتبطة بالبلاغات والمهام.
  • تحسين كفاءة المنصة وأمانها ومعالجة الأعطال والمشكلات الفنية.

3. استخدام Gmail API

تستخدم المنصة Gmail API لغرض إرسال رسائل بريد إلكتروني تشغيلية فقط، مثل إشعار المتطوع بأنه تم ترحيل بلاغ جديد إليه.

تستخدم المنصة صلاحية الإرسال فقط (gmail.send)، ولا تستخدم هذه الصلاحية لقراءة صندوق البريد أو الاطلاع على الرسائل أو جهات الاتصال. ولا يتم استخدام بيانات Google لأغراض إعلانية أو تسويقية.

4. حماية البيانات

نستخدم ضوابط وصول وصلاحيات فنية للمساعدة في حماية البيانات من الوصول أو الاستخدام غير المصرح به. كما يتم حفظ بيانات الاعتماد الحساسة الخاصة بالخدمات الخارجية في بيئة خادم آمنة وليست ضمن واجهة الموقع العامة.

5. مشاركة البيانات

لا نبيع البيانات الشخصية. وقد تتم معالجة بعض البيانات عبر مزودي خدمات تقنية تستخدمهم المنصة لتقديم خدماتها، وذلك بالقدر اللازم لتشغيل الموقع وإرسال التنبيهات وحفظ البيانات.

6. الوصول إلى بيانات البلاغات

يتم تقييد بيانات البلاغات بحسب الصلاحيات والدور الوظيفي داخل النظام. ويصل المتطوع إلى تفاصيل البلاغات المخصصة له وفق آلية تشغيل المنصة والصلاحيات المعتمدة.

7. الاحتفاظ بالبيانات

نحتفظ بالبيانات للمدة اللازمة لأغراض التشغيل والالتزامات النظامية والأمنية، وقد تختلف مدة الاحتفاظ بحسب نوع البيانات وطبيعة استخدامها.

8. التعديلات على سياسة الخصوصية

قد يتم تحديث هذه السياسة عند تطوير المنصة أو إضافة خدمات جديدة. وسيتم نشر النسخة المحدثة في هذه الصفحة.

9. التواصل

للاستفسارات المتعلقة بالخصوصية أو استخدام البيانات، يمكن التواصل مع جمعية ليث للإنقاذ عبر قنوات التواصل الرسمية المعلنة في الموقع.
